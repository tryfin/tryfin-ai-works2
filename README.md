# AI PROJECTS | TRYFIN INC.

Claude Codeとの対話から生まれた、ゲーム・Webサイト・ツールをまとめたAI開発実績ページです。
tryfin.co.jp の WORKS セクションと同じトンマナで構築しており、将来的に本サイトへ組み込むことを想定しています。

## 実績構成

Worksセクションは以下の2グループに分けて掲載しています。

- **CLIENT WORK** — tryfin.co.jp本サイトの実績流用（3件）: 基幹システムWEB移行、暗号資産確定申告サービス、決済システムUXUI支援
- **SELF DEVELOPED** — AI開発による自主制作（4件）: 予約サイト、パズルゲーム、シューティングゲーム、ストップウォッチツール

各カードにはサムネイル下に「System Migration」「Puzzle Game」のような簡潔な英字バッジを1つ添え、案件の性質・成果物種別を一目で示しています（色分けタグやタブ切り替えはなし）。
